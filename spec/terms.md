# Terms

## Primitive contracts

- **cache-app** — the small app a cache proof extracts, and what its config ignores.
  - Role: fact
  - Zone: core
  - Of: []
- **capability-app** — the capability case app's source inputs, as data a proof writes into a temporary project.
  - Role: fact
  - Zone: core
  - Of: []
- **case-inventory** — the independently supplied identities, conditions and input paths of the structural fixture cases.
  - Role: fact
  - Zone: core
  - Of: []
- **claim** — a promise declared once in its topic and proved by tests.
  - Role: fact
  - Zone: core
  - Of: []
- **command** — what a launcher hands a Kit command and what the command answers.
  - Role: fact
  - Zone: core
  - Of: []
- **comment** — supplied implementation text and its source location; it explains choices that other artifacts do not express.
  - Role: fact
  - Zone: core
  - Of: []
- **compiler-facts** — plain compiler observations about projects, settings, types, imports and authority entries supplied to the checks.
  - Role: fact
  - Zone: core
  - Of: []
- **declared-input** — explicit file, suffix-filtered tree and path-kind inputs, separated into data and code with a supplied key format and runtime identity.
  - Role: fact
  - Zone: core
  - Of: []
- **default-config** — the target layout, as the config an app starts from.
  - Role: fact
  - Zone: core
  - Of: []
- **exported-symbol** — a supplied exported name and its declaring file.
  - Role: fact
  - Zone: core
  - Of: []
- **file** — a supplied file in a snapshot, identified by its path.
  - Role: fact
  - Zone: core
  - Of: []
- **ignored-import** — the error for an import into a path the config ignores.
  - Role: derived
  - Zone: core
  - From: []
- **import** — a supplied relation from an importing file to the file it imports.
  - Role: fact
  - Zone: core
  - Of: []
- **layer** — a declared dependency position and its permitted import relationships.
  - Role: fact
  - Zone: core
  - Of: []
- **program-scope** — what every fact reader over one compiler program shares: the program, its checker, the checked sources and the app-relative path of a file.
  - Role: fact
  - Zone: substrate
  - Of: {{default-config}}
- **reference** — a marked use that points to the home of a term, topic or claim.
  - Role: fact
  - Zone: core
  - Of: []
- **runs** — what `kit runs` recorded: the digest of each placed module and test, and the named functions each test ran.
  - Role: fact
  - Zone: core
  - Of: []
- **snapshot** — the supplied files, declarations, configuration and compiler facts of one codebase.
  - Role: fact
  - Zone: core
  - Of: {{claim}}, {{comment}}, {{compiler-facts}}, {{default-config}}, {{exported-symbol}}, {{file}}, {{import}}, {{reference}}, {{term}}
- **snapshot-cache** — one stored extraction and the reads its trace replays, with the index and environment that key it.
  - Role: fact
  - Zone: core
  - Of: []
- **term** — a concept defined once in the global terms file, with its meaning and any declared contract metadata.
  - Role: fact
  - Zone: core
  - Of: []
- **topic** — the unit the maintainer ratifies and the agent works from; it explains why its modules exist and how they compose.
  - Role: fact
  - Zone: core
  - Of: []
- **verification** — the supplied checks, input identities, execution contracts, evidence and resource state of a verification request.
  - Role: fact
  - Zone: core
  - Of: []
- **zone** — what code may do: core, shell or substrate.
  - Role: fact
  - Zone: core
  - Of: []

  - Zone: core

- **claim-proof-binder** — findings from matching claim declarations and topic-first test names.

  - Zone: core

- **claim-runs** — what each claim's tests ran of each placed module, beside the claims that name it.

  - Zone: core

- **comment-check** — the check that comments cite nothing and carry no debt.
  - Role: derived
  - Zone: core
  - From: {{zone}}, {{claim-proof-binder}}, {{finding}}, {{placement-of}}, {{layer}}, {{snapshot}}
- **compiler-check** — the check that checked files are compiled strictly, without errors or escape hatches.
  - Role: derived
  - Zone: core
  - From: {{capability-context}}, {{snapshot}}
- **config-values** — the values a Kit configuration declares, checked as they are read: mappings, text, zones and relative locations.
  - Role: derived
  - Zone: core
  - From: {{default-config}}
- **construction-check** — the check that only an adapter builds its contract's values and only a declared core producer its write descriptions.
  - Role: derived
  - Zone: core
  - From: {{finding}}, {{placement-of}}, {{snapshot}}
- **consumer-report** — what one app check reports for that app: its failures by check beside the Kit commit it pins.
  - Role: derived
  - Zone: core
  - From: []
- **coverage-report** — the named functions an LCOV report lists for each file, by start line, and how often each ran.
  - Role: derived
  - Zone: core
  - From: []
- **dependency-check** — findings from import direction and cycles between placed modules.
  - Role: derived
  - Zone: core
  - From: {{finding}}, {{placement-of}}, {{snapshot}}
- **dependency-exclusions** — findings and limits from the explicit separations an app declares between selected code.
  - Role: derived
  - Zone: core
  - From: {{finding}}, {{placement-of}}, {{snapshot}}
- **edge-check** — findings from import edges among checked code: entrypoint imports, layer and zone direction, legacy edges and cycles.
  - Role: derived
  - Zone: core
  - From: {{capability-context}}, {{dependency-check}}, {{snapshot}}
- **excerpt-cohesion** — debt from a module holding the excerpts of two or more claims: code only one claim runs, held by no code others run.
  - Role: derived
  - Zone: core
  - From: {{claim-runs}}, {{finding}}, {{placement-of}}, {{runs}}, {{snapshot}}
- **finding** — what a check reports: its rule, a path, the fix and a debt key.
  - Role: derived
  - Zone: core
  - From: []
- **fixture-config** — the adapter boundaries of the structural fixture derived by extending the default configuration.
  - Role: derived
  - Zone: core
  - From: {{default-config}}
- **fixture-files** — the files of a compiler fixture: a strict project over the declared roots, with the given sources.
  - Role: derived
  - Zone: core
  - From: {{default-config}}
- **fixture-snapshot** — a headless snapshot derived from supplied case descriptions for structural proofs.
  - Role: derived
  - Zone: core
  - From: {{comment}}, {{default-config}}, {{exported-symbol}}, {{file}}, {{import}}, {{snapshot}}, {{term}}
- **function-governance** — debt from the named functions of a module that no claim naming it runs.
  - Role: derived
  - Zone: core
  - From: {{claim-runs}}, {{finding}}, {{runs}}, {{snapshot}}
- **global-authority** — what a module acquires through ambient globals, and which uses need a declared adapter.
  - Role: derived
  - Zone: core
  - From: {{capability-context}}, {{snapshot}}
- **handover-check** — findings where code outside the zones hands placed code behaviour that is no adapter contract.
  - Role: derived
  - Zone: core
  - From: {{finding}}, {{placement-of}}, {{snapshot}}
- **import-authority** — what a module acquires by importing outside the checked code: adapter packages, entrypoint packages and declared package rows.
  - Role: derived
  - Zone: core
  - From: {{capability-context}}, {{snapshot}}
- **layout-check** — findings from comparing file roles with configured target roots and existing legacy locations.
  - Role: derived
  - Zone: core
  - From: {{finding}}, {{placement-of}}, {{snapshot}}
- **layout-configuration** — the layout an app opts into: its existing legacy locations.
  - Role: derived
  - Zone: core
  - From: {{config-values}}
- **legacy-size** — the size of each legacy module as debt: its statements, and how many of them only call into placed modules.
  - Role: derived
  - Zone: core
  - From: {{finding}}, {{placement-of}}, {{snapshot}}
- **legacy-zone-configuration** — the zones legacy code is declared in, by root or by exact files.
  - Role: derived
  - Zone: core
  - From: {{config-values}}, {{default-config}}
- **module-references** — the check that every placed module is named by a claim it keeps, and the claims each module keeps.
  - Role: derived
  - Zone: core

  - Zone: core

  - Role: derived
  - Zone: core

  - Zone: core

## Supporting vocabulary and roles

- **capability** — access to an operation a module may perform.
- **check** — a reading that reports findings for a rule.
- **config** — what an app declares to the kit.
- **core** — the zone that decides everything and performs no effect.
- **cycle** — a dependency path that returns to its starting module.
- **debt-key** — a finding's stable name, which a debt list holds.
- **file-type** — what a file is: source, test, spec or other.
- **heading** — the spec line that carries a module's identity.
- **import-edge** — one file's import of another.
- **inventory** — the collected declarations and references read from a document.
- **kit** — the checks, their spec and their config, applied to an app.
- **legacy** — a source file that is not placed.
- **maintainer** — the person who ratifies the spec and approves each change to the kit.
- **marker** — the notation identifying a declaration or reference.
- **module** — one named contract, at `<zone>/<layer>/<name>`, defined once in the terms file.
- **placed** — at `<zone>/<layer>/<name>`, and so held to the placement rules.
- **placement** — a module's declared zone, layer and name.
- **proof** — a test that establishes a claim.
- **prose** — any text of the spec.
- **public** — importable from another zone under the inward dependency rule.
- **read** — to take a snapshot of a codebase.
- **resolved** — matched to exactly one existing home in the intended namespace.
- **result** — the value returned by a reading or composition.
- **rule** — one of R1–R4; every check serves one.
- **semantic** — identifying a defined meaning rather than matching an ordinary word.
- **spec** — the prose the maintainer ratifies.
- **statement** — one TypeScript statement, wherever it is nested; a block or an empty statement is not counted.
- **workspace** — the project files and settings a compiler loads.
